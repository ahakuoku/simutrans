# TID 連動盤（外部信号制御盤）— 試作（OTRP v62.0.3 ベース）

外部の盤（Web 盤・物理盤など）から、駅の信号と進路（番線の選択）を扱うための機能。
設計は `documentation/interlocking_panel_design_ja.md` を参照。

| ファイル | 内容 |
|---|---|
| `interlocking.h` | 本体から呼ぶフック関数の宣言。`TID_INTERLOCKING` の定義 |
| `il_hooks.cc` | フック関数の実装（薄い中継） |
| `il_manager.*` | 連動装置本体（連動駅・てこ扱い信号・進路・判定・自動解除・セーブ） |
| `il_tool.*` | `TOOL_INTERLOCKING`（盤の操作をネットワーク同期するツール） |
| `il_bridge.*` | 外部の盤とつなぐ窓口（127.0.0.1 のみ。HTTP と行単位プロトコル） |
| `il_query.*` | 盤の配線略図・駅一覧のための読み取り専用の問い合わせ |
| `il_json.h` | JSON 出力の補助 |
| `panel/index.html` | Web 盤（ゲームが配信する） |
| `PROTOCOL.md` | 盤との通信の仕様 |
| `PORTING.md` | 新しい OTRP への移植手順 |
| `hooks.patch` / `check_hooks.sh` | 移植用のパッチと確認スクリプト |
| `tests/` | ヘッドレスで動かす自動テスト（シナリオ `il-test`、`run_test.py`、Web 盤の `panel_test.mjs`） |
| `tools/il_cli.py` | 手で試すための簡易コンソール盤 |
| `tools/build_windows.sh` | Linux 上で Windows 64bit 版をクロスビルドするスクリプト（MinGW） |

## 使い方（Web 盤）

1. 盤のファイルを置く: `interlocking/panel/` フォルダを、Simutrans のフォルダに `interlocking_panel` という名前でコピーする。
   （ソースからビルドしてそのまま動かす場合は不要）
2. ゲームを起動してマップを開く。
3. ブラウザで **http://127.0.0.1:13360/** を開く。左上が「ゲームに接続中」になれば準備完了。

### 設定（「設定」タブ）

1. **連動駅を作る**: 駅を選んで「作成」。その駅の周りの配線略図が出る。
2. **表示する範囲**: 必要なら x / y の範囲を直して「範囲を適用」。
3. **入口**: 区域の外から駅に入れる線路が 1 本ずつ並ぶ。すべてが「✔」になるように、各行のボタンで入口の信号（場内信号）を登録する。
   「信号を通らずにホームへ入れます」と出た線路は、ゲーム内で駅に向かう信号を置く必要がある。
4. **出口**: 番線の端ごとに並ぶ。出発信号があれば登録、なければ「仮想出発信号にする」。
   仮想出発信号はマップに何も置かない出発信号で、扱者モードのときだけ、出発進路を引くまで列車をホームで待たせる
   （行き止まり式ホームや、ホームの先に信号を置くと自動運転で困る番線向け）。停車する列車だけが対象。
4b. **留置線・引上線（入換）**: 区域内の行き止まりの線路が並ぶ。「仮想入換信号にする」と、扱者モードのとき、
   入換進路を引くまで列車をその線路で待たせる（マップには何も置かない）。列車を入れるには、ダイヤでその線路を経由地にする。
   列車全体がその線路に収まる長さが必要（はみ出すと、先頭が線路の外に出ていて待たせられない）。
5. **その他の信号**（折りたたみ）: 自動判定に出ない信号を手で登録したいとき。地図上の信号クリックでも登録・解除できる。
6. **進路**: 「進路を自動作成」で、入口の信号 → 各番線・留置線、出発信号・仮想出発信号 → 区域の出口、
   仮想入換信号 → 各番線 の進路ができる。進路の名前は各行の「名前」で変えられる。
   足りないものは「手で作る」で、始点の信号 → 着点の線路の順にクリックして作る。

### 地図の表示（地図の上のボタン）

- **この駅につながる線路だけ**（初期状態でオン）: ホームから線路のつながりをたどり、各方向の「いちばん外側の分岐より外にある
  最初の信号」までを表示する。つながっていない別線（上や下を通る高架・地下の線）や隣の駅は薄く表示され、クリックできない。
- **高さ**（地上・高架・地下）: 高さごとに表示を切り替える。同じ場所で重なっている線路は、高さごとに少しずらして描く。
- 信号やタイルにマウスを重ねると、座標と高さ（例「地下（高さ -3）」）が出る。
- **回転**: 「↻ 回転」を押すたびに地図が時計回りに 90° 回る。縦（南北）に引かれた駅も、実物の盤のように横向きに表示できる
  （地図の上の帯の右端に、いつも方位マーク「北↑」などを表示）。向きは駅ごとにブラウザに保存され、ゲームのデータは変わらない。
- **拡大・縮小**: 地図の上の「－」「＋」、または地図の上で Ctrl＋マウスホイール（カーソルの位置を中心に拡大）。真ん中の「100%」で元に戻る。
- **会社で絞り込み・並べ替え**: 設定タブの駅一覧は会社ごと・名前順に並び、上の欄で会社を絞り込める。てこ扱い信号の一覧は「会社ごと」「位置（北から）」で並べ替えられる。

### 運転（「運転」タブ）

1. 上の「**扱者**」を押す（扱者モード）。てこ扱い信号は、進路を引くまで停止を示す。
2. 列車が信号で待つと「接近表示」に出る（仮想出発信号の番線は「発車待ち」、仮想入換信号の線路は「入換待ち」）。
3. 進路の引き方（実物の盤と同じ操作）:
   1. 地図上の**信号てこ**（白枠の信号、四角の仮想出発信号、ひし形の仮想入換信号）を押す。
   2. 進路を引ける**着点ボタン**（番線・留置線・出口・車庫）が黄色く点滅する。
   3. 着点ボタンを押すと、その場で進路ができる。ポイントは自動で転換・鎖錠される。
   - 設定中の進路は、同じ信号てこをもう一度押すと取り消せる（列車の進入前だけ）。
4. **転てつてこ**（ポイント）: 「自動／定位／反位」の 2 位置＋自動。固定すると、その向きを通る進路しか引けなくなる。
   進路が通っている間は鎖錠され、進路の向きが表示される。
   - 定位 = 直進。反位 = 分岐側。分岐線がその先どちらへ曲がるかで、実物の分岐器の向きを自動で判定する。
   - Simutrans の分岐タイルだけが通せる（実物の分岐器にない）組み合わせは「その他」として小さく表示する。
   - 渡り線（分岐線が 3 マス以内で別のポイントの分岐側につながるもの）は **双動**（「22号イ・ロ」）として 1 本のてこにまとめる。
   - てこの位置はゲームのデータに保存され、ネットワークゲームでは全員に同じ向きが見える。固定したポイントに反する進路
     （ショートカットも含む）は、ゲーム側の連動装置が拒否する。
5. **ショートカット**: 設定タブで登録した進路（「進路を自動作成」など）は、ボタン1つで引ける。
6. 列車が通過すると、進路は自動で解除される。「自動」に戻すと、信号は通常の自動運転に戻る。

### 名称（設定タブの「7. 名称」）

信号・番線・留置線・出口・ポイントに好きな名前を付けられる（登録済みの進路の名前は「6. 進路」の「名前」で変える）（空欄で自動の名前に戻る）。名前はセーブデータに保存され、ネットワークゲームでは全員に同じ名前が見える。

### 時刻表と番線の関係

時刻表で決まるのは**停車する駅**。盤で同じ駅の別の番線への進路を引くと、列車はその番線に停車して客扱いし、時刻表の次の駅へ進む（時刻表で指定した番線と違っていてよい）。
着点が停車駅以外の場合は、着点から時刻表の行き先へ向かう。行けない場合は信号を停止のままにして「誤進路」と表示する。

ネットワークゲームでも、各自のパソコンでブラウザから自分のゲームに接続して使う。操作はサーバ経由で全員に同期される。

## 手で試す（コンソール）

`python3 interlocking/tools/il_cli.py` で接続し、`PROTOCOL.md` のコマンドを打つ（例: `cmd st_mode,1,1`）。

## 試作版の制約

- 連動区域の入口はすべててこ扱い信号にすること（区域内に自動信号の列車が入り込むのを防ぐ仕組みは入れていない）。
- 進路の途中に、てこ扱いでない信号を置かないこと。
- 車庫・側線などの抜け道の検査は未実装（P1）。
- 盤の設定（表示範囲）はブラウザに保存される。別のブラウザやパソコンでは範囲を指定し直す。
- 接近鎖錠（時素）はない。列車が進入する前なら、いつでも進路を戻せる。
