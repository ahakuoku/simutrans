# TID 連動盤（外部信号制御盤）— 試作（OTRP v62.0.3 ベース）

外部の盤（Web 盤・物理盤など）から、駅の信号と進路（番線の選択）を扱うための機能。
設計は `documentation/interlocking_panel_design_ja.md` を参照。

| `il_manager.*` | 連動装置本体（連動駅・てこ扱い信号・進路・判定・自動解除・セーブ） |
| `il_tool.*` | `TOOL_INTERLOCKING`（盤の操作をネットワーク同期するツール） |
| `il_bridge.*` | 外部の盤とつなぐ窓口（127.0.0.1 のみ。HTTP と行単位プロトコル） |

| `panel/` | Web 盤（ゲームが配信する）。`index.html`・`panel.css`、共通の `core.js`・`operate.js`・`render.js`・`actions.js`、継電の盤の `relay.js` |

## 使い方（Web 盤）

1. 盤のファイルを置く: `interlocking/panel/` フォルダを、Simutrans のフォルダに `interlocking_panel` という名前でコピーする。
   （ソースからビルドしてそのまま動かす場合は不要）
2. ゲームを起動してマップを開く。
3. ブラウザで **http://127.0.0.1:13360/** を開く。左上が「ゲームに接続中」になれば準備完了。

### 設定（「設定」タブ）

1. **連動駅を作る**: 駅を選んで「作成」。その駅の周りの配線略図が出る。
2. **表示する範囲**: 必要なら x / y の範囲を直して「範囲を適用」。
3. **入口**: 区域の外から駅に入れる線路が 1 本ずつ並ぶ。すべてが「✔」になるように、各行のボタンで入口の信号（場内信号）を登録する。
   「信号を通らずにホームへ入れます」と出た線路は、ゲーム内で駅に向かう信号を置く必要がある。
4. **出口**: 番線の端ごとに並ぶ。出発信号があれば登録、なければ「仮想出発信号にする」。
   仮想出発信号はマップに何も置かない出発信号で、扱者モードのときだけ、出発進路を引くまで列車をホームで待たせる
   （行き止まり式ホームや、ホームの先に信号を置くと自動運転で困る番線向け）。停車する列車だけが対象。
4b. **留置線・引上線（入換）**: 区域内の行き止まりの線路が並ぶ。「仮想入換信号にする」と、扱者モードのとき、
   入換進路を引くまで列車をその線路で待たせる（マップには何も置かない）。列車を入れるには、ダイヤでその線路を経由地にする。
   列車全体がその線路に収まる長さが必要（はみ出すと、先頭が線路の外に出ていて待たせられない）。
5. **その他の信号**（折りたたみ）: 自動判定に出ない信号を手で登録したいとき。地図上の信号クリックでも登録・解除できる。
6. **進路**: 「進路を自動作成」で、入口の信号 → 各番線・留置線、出発信号・仮想出発信号 → 区域の出口、
   仮想入換信号 → 各番線 の進路ができる。進路の名前は各行の「名前」で変えられる。
   足りないものは「手で作る」で、始点の信号 → 着点の線路の順にクリックして作る。

### 接続区間の在線・OuDiaSecondV2

画面上部の表示モードで「全区間在線」を選ぶと、「運転」に接続区間の在線一覧、
「設定」にOuDiaSecondの読込・照合設定を表示する。初期表示は「連動盤」で、
従来の配線略図・自動／扱者・電気／継電の操作は従来モードで使用する。表示モードの選択はブラウザに保存する。
従来モードでは全区間の在線APIを問い合わせない。連動駅の作成や変更も従来モードの「設定」で行う。

新規モードは、選択した連動駅の全ホームから線路をたどり、つながる全区間の列車を約2秒ごとに一覧表示する。
列車がいなくても、接続区間の線形・ホーム・駅名・信号の配置と現示を地図に表示する。
「＋」「−」で拡大・縮小、「全体を表示」で全区間に合わせる。拡大時はスクロールで移動できる。
駅名と運用番号は地図の縮尺によらず画面上で14pxの大きさを保ち、近接する文字は位置をずらして引出線で元の位置を示す。
地図の列車ラベルには運用番号・列車番号・種別・行先・遅延情報を表示する。在線一覧にも同じ照合結果・遅延情報を表示する。
遅延が1分以上の場合だけ、遅延情報の行を赤色で表示する。列車番号・行先の文字色は変えない。

遅延情報は、一意に照合できた列車について、停車中はゲームの実到着時刻とダイヤの着時刻の差を表示する（「到着基準」）。
所定の発車時刻を過ぎても停車中で、その遅れが到着時点の遅れを上回った場合は「発車待ち」の遅延を表示する。
始発駅で所定発車時刻まで待っている場合は定刻として扱う。
走行中はゲームの残経路に基づく次駅到着見込みとダイヤの着時刻を比較し、「推定遅延」「定刻見込」「早着見込」と表示する。
日付をまたぐ時刻にも対応し、分・秒と判定基準の駅名を表示する。
ダイヤ未選択・候補複数・駅名不一致・必要な実時刻や到着見込みがない場合は「遅延不明」とする。
走行中の値は実測の通過遅延ではなく到着予測であり、信号待ちなどで変動する。
全区間在線の到着予測は、残経路の各タイルの制限速度、斜め区間の移動ステップ数、現在タイル内の進行量、
駅の停止位置と減速速度、ゲームの移動速度倍率から計算する。通過済み区間の平均制限速度や一律の速度低減補正は使わない。
加速過程・勾配・曲線抵抗・将来の信号待ちは完全には再現しないため、実際の走行条件による予測の変動は残る。

ゲームとOuDiaSecondの駅名が異なる場合は、全区間在線モードの「設定」→「駅名エイリアス」で
「対応を追加」を押し、左にゲーム内の駅名、右にOuDiaSecondの駅名を入力して「エイリアスを保存」を押す。
入力欄には取得済みのゲームの駅名・読込ダイヤの駅名が候補として出る。候補にない名前も直接入力できる。
停車中の列車特定・到着遅延・発車待ち遅延と、走行中の次駅到着見込みによる遅延のすべてに適用する。
画面上部の「駅名：ゲーム内／エイリアス」で表示を切り替えられる（初期値はゲーム内）。
全区間在線では地図の駅名・在線位置の駅名・遅延基準の駅名に、連動盤では地図の駅名・駅選択・接近表示の次駅・駅属性の留置線の自動名称に適用する。
未設定の駅は元の名前を表示する。列車の行先はダイヤの表記を使い、手動の盤ラベルや進路名は維持する。
表示方法はブラウザに保存し、両モードで共通に使用する。照合には表示方法にかかわらずエイリアスを適用する。
1つのゲーム駅名に対応先は1つだけ指定でき、複数のゲーム駅名を同じダイヤ駅名に対応させることもできる。
エイリアスはゲーム本体の共通設定として、全連動盤・別ブラウザ・同じネットワークゲームの別PCに反映する。
各盤は状態取得時に共通設定を読み直すため、開いたままの盤にも反映される。ゲームのセーブデータにも保存する。
駅やダイヤを読み替えても維持する。行を削除して保存すると全連動盤で対応を解除する。
他の盤で編集している間に保存すると、自分が変更した行だけを更新する。同じ駅名への変更は最後の保存を採用する。
エイリアスは512件、駅名は各UTF-8で512バイトまで。
共有には更新済みのゲーム本体が必要。駅名の表示方法やダイヤの読込・選択は引き続きブラウザごとに指定する。
在線タイルを赤く表示し、列車の位置に運用番号を添える。信号にマウスを重ねると種類・座標・現示を確認できる。
ダイヤの読込・選択は任意。未読込でも、またダイヤ欄で「選択しない（在線表示のみ）」を選んでも、運用番号・位置・在線タイル数を表示する。
ファイル読込後もダイヤは未選択とし、列車番号・種別・行先を照合したいときに選択する。
配線略図の表示範囲や信号・ポイントの向きでは打ち切らない。坂・橋・トンネルを含む線路の実際の接続を使い、
線路がつながっていない高架・地下の交差は含まない。車庫内の編成は除く。
一覧の座標は編成の先頭位置、在線タイル数は接続区間内に車両が実在するタイル数で、線路の予約とは区別する。

1. OuDiaSecondV2で運用情報を設定・更新して `.oud2` を保存する。
2. 盤の「設定」→「OuDiaSecondV2 運用情報」でファイルを選択し、照合するダイヤ（平日など）を選ぶ。
3. 早発・遅延の許容時間をそれぞれ秒で設定する（初期値は早発120秒、遅延1800秒、0〜86399秒）。

車両名を運用番号として使い、先頭の `(123)` または `（１２３）` のような数字だけの括弧を除いて照合する。
OuDiaSecondの `OperationNumberN`（途中の運用変更・併結の複数運用を含む）、または保存された `OperationTable` を読む。
これらを保存しない旧版（2.06.23など）のファイルでは、`Operation駅番号B/A` に保存された駅作業から運用を復元する。
出区・路線外始発の運用番号を起点に、駅・番線・時刻での次列車接続、入換、入出区連携コード、
入れ子の増結・解結、運用番号変更・順序反転、分岐・環状の駅参照、起点時刻跨ぎ設定を使用する。
同一番線・同時刻の接続が競合する場合や、番号の起点がなく復元できない場合は運用番号を推測しない。
新版の保存済み運用がある列車は、保存された情報を優先する。
列車番号・種別・ダイヤ上の終着駅名を表示する。UTF-8・Shift_JISのファイルに対応する。
ゲームの1か月を24時間とする `hh:mm:ss` の時刻で照合し、深夜跨ぎ・24時以降の時刻も扱う。
走行中はその運用の開始〜終了時刻、停車中に駅名が一致するときはその駅の着発時刻を照合範囲とし、
開始側に早発許容、終了側に遅延許容を加える。許容時間内の候補が複数なら全候補を表示し、範囲外なら「列車未特定」とする。
運用番号と時刻だけで一意にならない列車を推測で確定しない。駅名での絞り込みには駅名の一致、または駅名エイリアスの設定が必要。
折り返し前後の許容時間が重なる場合は、ゲームが持つ「直前の停車駅（停車中は現在駅）→次のスケジュール駅」と、
ダイヤ上の駅順序を比較する。逆方向の前列車を候補から除外し、折り返し後の列車を表示する。
この判定にも駅名エイリアスを適用する。駅情報が不足する場合や同方向の複数候補が残る場合は、推測で1列車に確定しない。

読込データ・ダイヤ選択・許容時間はブラウザに保存する。ファイルを更新した場合は選び直す。
一覧表示には、このAPIに対応したゲーム本体と、新しい `traffic.js` を含む盤のファイル一式が必要。

検証: `node interlocking/tests/panel_traffic_test.mjs`。
ブラウザ回帰テストは `node interlocking/tests/panel_traffic_browser_test.mjs`（Playwrightが必要）。
共有エイリアスの保存形式テストは `g++ -std=c++14 -O2 interlocking/tests/aliases_blob_test.cc -o aliases_blob_test` でビルドして実行する。
インストール済みEdgeで動かす場合は `PLAYWRIGHT_CHANNEL=msedge` を設定する。

### 地図の表示（地図の上のボタン）

- **この駅につながる線路だけ**（初期状態でオン）: ホームから線路のつながりをたどり、各方向の「いちばん外側の分岐より外にある
  最初の信号」までを表示する。つながっていない別線（上や下を通る高架・地下の線）や隣の駅は薄く表示され、クリックできない。
- **高さ**（地上・高架・地下）: 高さごとに表示を切り替える。同じ場所で重なっている線路は、高さごとに少しずらして描く。
- 信号やタイルにマウスを重ねると、座標と高さ（例「地下（高さ -3）」）が出る。
- **回転**: 「↻ 回転」を押すたびに地図が時計回りに 90° 回る。縦（南北）に引かれた駅も、実物の盤のように横向きに表示できる
  （地図の上の帯の右端に、いつも方位マーク「北↑」などを表示）。向きは駅ごとにブラウザに保存され、ゲームのデータは変わらない。
- **拡大・縮小**: 地図の上の「－」「＋」、または地図の上で Ctrl＋マウスホイール（カーソルの位置を中心に拡大）。真ん中の「100%」で元に戻る。
- **会社で絞り込み・並べ替え**: 設定タブの駅一覧は会社ごと・名前順に並び、上の欄で会社を絞り込める。てこ扱い信号の一覧は「会社ごと」「位置（北から）」で並べ替えられる。

### 運転（「運転」タブ）

1. 上の「**扱者**」を押す（扱者モード）。てこ扱い信号は、進路を引くまで停止を示す。
2. 列車が信号で待つと「接近表示」に出る（仮想出発信号の番線は「発車待ち」、仮想入換信号の線路は「入換待ち」）。
   列車が路線に入っていれば路線名を出す。「【会社】[○○線][快速] Ａ～Ｂ」のような名前なら、最後の [ ]（種別）を色付きの札にし、
   【会社】は省いて、残り（[○○線] Ａ～Ｂ）を小さく出す。[ ] のない名前は全体が札になる。続けて列車名と次の停車駅を出す。
   継電の盤の接近電響は、場内信号など信号で待つ列車だけで鳴る（発車待ちでは鳴らない）。
3. 進路の引き方（実物の盤と同じ操作）:
   1. 地図上の**信号てこ**（白枠の信号、四角の仮想出発信号、ひし形の仮想入換信号）を押す。
   2. 進路を引ける**着点ボタン**（番線・留置線・出口・車庫）が黄色く点滅する。
   3. 着点ボタンを押すと、その場で進路ができる。ポイントは自動で転換・鎖錠される。
   - 設定中の進路は、同じ信号てこをもう一度押すと取り消せる（列車の進入前だけ）。
4. **転てつてこ**（ポイント）: 「自動／定位／反位」の 2 位置＋自動。固定すると、その向きを通る進路しか引けなくなる。
   進路が通っている間は鎖錠され、進路の向きが表示される。
   - 定位 = 直進。反位 = 分岐側。分岐線がその先どちらへ曲がるかで、実物の分岐器の向きを自動で判定する。
   - Simutrans の分岐タイルだけが通せる（実物の分岐器にない）組み合わせは「その他」として小さく表示する。
   - 渡り線（分岐線が 3 マス以内で別のポイントの分岐側につながるもの）は **双動**（「22号イ・ロ」）として 1 本のてこにまとめる。
   - てこの位置はゲームのデータに保存され、ネットワークゲームでは全員に同じ向きが見える。固定したポイントに反する進路
     （ショートカットも含む）は、ゲーム側の連動装置が拒否する。
5. **ショートカット**: 設定タブで登録した進路（「進路を自動作成」など）は、ボタン1つで引ける。
6. 列車が通過すると、進路は自動で解除される。「自動」に戻すと、信号は通常の自動運転に戻る。

### 継電連動（上級者向け）

設定タブの「0. 連動装置の種類」で、駅ごとに **電子連動**（上の扱い方）と **継電連動** を選べる。継電連動では盤の色が変わり、
右側にてこが並ぶ。

1. **信号てこ**（赤。入換信号機は白）を、進路を開通させる方向（盤の上の左・右）に**ひねる**。
   右の盤では、つまみを押すと開通方向にひねる／定位に戻す。◀ ▶ のボタンでも左右に倒せる。
   信号てこは地図の上（信号・出発点の位置、線路のすぐ脇）にも表示され、押すと同じように扱える
   （地図の上の「地図にてこ」で表示を切り替え。マウスを重ねると右の盤の同じてこが光る）。
2. その方向の**着点ボタン**（線路の上の丸い押しボタン。横の札に番線・出口の名前）が点灯するので押す。向きの違うポイントは**転換時間**のあいだ動き（表示灯が点滅）、
   すべて転換して鎖錠されてから信号が進行になる。
3. 列車が通過しても**てこは反位のまま**。次の進路の前に、てこを**定位に戻す**（もう一度押す）。
4. 列車が接近中にてこを戻すと**接近鎖錠**がかかり、**時素**（本線 90 秒・入換 30 秒。設定タブで変更可）がたってから進路が解ける。
5. **転てつてこ**（黒）は ◀N（定位）・つまみ＝C（総括。進路に合わせて自動で転換）・R▶（反位）。N・R の表示灯はポイントの実際の向き。
   表示灯の意味は、右の盤の下の凡例にある。
   **信号てこをまとめる**: 設定タブ「0.」で、2 つの信号を 1 本のてこにまとめられる（左に倒すと一方、右に倒すと他方。例：上り出発・下り出発）。
   盤では「1L／1R」のように表示され、◀L・R▶ で倒す。同時に倒せるのは片側だけ。
   **入換てこ**: 設定タブ「0.」の「入換てこ」で、信号・出発点に入換用のてこを付けられる（白＝入換信号機、緑＝入換標識）。
   入換てこで光る着点は番線・留置線・車庫だけ（出口は出ない）。
   **縦列停車**: 番線や留置線に列車が止まっているとき、緑の入換てこでは「〇〇手前」の着点が光り、止まっている列車の
   すぐ後ろまで進路が取れる。進入する列車は、全体が収まるときだけ進入する。後から入った列車は、そこで到着・停車扱いになる。
6. **一斉停止てこ**: 反位の間、駅のすべての信号を停止にする。**駅扱切換てこ**: 集中（自動）／駅扱（扱者）。
   **接近電響**（切・入のスイッチ）と **電響確認**（押しボタン）: スイッチが「入」のとき、列車が信号で待つと電響が鳴り続け、
   確認ボタンのランプが点滅する（「鳴動中」）。確認ボタンを押すと止まり、次の列車でまた鳴る。列車が信号で待たなくなっても止まる。
   このブラウザだけの設定で、どのタブを開いていても鳴る。
   ブラウザは、ページを開いてから一度もクリックしていないと音を出さない。ページを読み込み直したら、画面のどこかを一度クリックする（盤に「画面を一度クリックすると鳴ります」と出る）。
7. ショートカット（登録済みの進路）と「進路を自動作成」は使えない。盤の向き（回転）は全員共通でゲームに保存される。

時間はゲーム内の時間（通常速度のときの秒）で数えるので、ネットワークゲームでも全員の盤が同じに動く。早送り中は速く過ぎる。

### 操作できる会社

連動駅は作った会社のもの。設定タブの「0.」で、ほかに操作できる会社を選べる（直通運転の駅など）。
盤の操作は、ゲームで操作中の会社として行われる。操作できない会社のときは、上に黄色い警告が出る。

### 留置線（設定タブの「4b.」）

- 区域内の行き止まりの線路（留置線・引上線）が自動で並ぶ。
- **駅属性の留置線**: 区域につながるほかの駅が「ほかの駅を留置線として扱う」に並ぶので、チェックする
  （名前に「留置」「引上」「電留」などが入った駅は、最初に一度だけ自動でチェックされる）。チェックした駅の線路は、
  この駅の区域の線路・留置線（着点ボタン・仮想入換信号の対象）になる。
- **両端から出られる線路**は、端ごとに仮想入換信号を置ける。列車は出ていく向きの端の信号で待つ。

### 名称（設定タブの「7. 名称」）

信号・番線・留置線・出口・ポイントに好きな名前を付けられる（登録済みの進路の名前は「6. 進路」の「名前」で変える）（空欄で自動の名前に戻る）。名前はセーブデータに保存され、ネットワークゲームでは全員に同じ名前が見える。

### 通過列車

仮想出発信号のある番線を**通過する**列車（その駅に止まらない列車）は、場内の進路（場内てこ→番線の着点）と
出発の進路（出発てこ→出口の着点）の**両方が揃うまで場内信号で待ち**、揃うとそのまま通過する。
場内の進路だけでは進入しない（仮想出発信号を素通りしないため）。止まる列車は今までどおり、場内の進路だけで進入して番線に止まる。

### 縦列停車と誘導

番線・留置線に列車が止まっているとき、その手前までの進路は **緑の入換てこ（入換標識）** か **ピンクのてこ（誘導信号）** でだけ取れる
（電子・継電とも）。設定タブ「0.」の「入換てこ」で、信号・出発点ごとに 白／緑／ピンク を付ける。
電子の盤では、出発点の後ろの小さな色付きのボタンが入換てこで、押してから着点ボタン（「〇〇手前」）を押す。
緑は入換進路、ピンクは列車の進路として扱う（時素の秒数が違う）。進入する列車は、全体が収まるときだけ進入する。

### 配線を読み直す（ゲームで線路を作り直したとき）

設定タブ「0.」の **配線を読み直す** を押すと、今の配線に合わせる（押したときだけ。自動ではしない）。

- 撤去された信号を駅から外す（その信号からの進路、てこのまとめ・入換てこ・区分の設定も消す）
- 番線・留置線の長さや端が変わったら、仮想出発信号を合わせる（端が動いたら、その出発点の設定も一緒に移す）。線路がなくなったら外す
- なくなったポイントの転てつてこ、なくなった留置線の駅を外す
- 登録した進路が今の線路で通れないときは、同じ始点・着点で引き直す。引けないものは「通れなくなった進路」として出すので作り直す
- 使用中の進路は見ない（解除してからもう一度押す）
- 新しく置いた信号は自動では登録しない（表示範囲の未登録の信号を一覧に出す）

結果は設定タブとログに出る。

### カスタム盤（駅ごとの盤面）

地図の上のバーの **カスタム盤を作る** を押すと、今の略図（表示範囲・向き）から下書きができる。
線路はまっすぐな線にまとめられ、信号てこ・入換てこ・ポイント・着点ボタン・番線がその上に並ぶ。

- 編集：部品を押して選び、ドラッグで動かす（方眼はゲームの 1 マス＝2 目）。線路の線は、両端の黄色い四角をドラッグして伸ばしたり斜めにしたりできる。
  2 本の線がつながった角（ポイントのない曲がり）の端をドラッグすると、両方の線が一緒に動く（L 字をそのまま斜めにできる）。
  選んである部品をもう一度押すと、その下に重なった部品が順に選ばれる（ポイントの下の短い線など）。
- 「＋線路」を押してから盤の上をドラッグすると線が引ける（何本でも。もう一度押すか Esc でやめる）。両端がポイント・線路の上なら、
  その間のゲームの線路に自動で結びつく（渡り線・シーサスの斜めの線など）。どこにも結びつかない線は飾りの線になる。
  矢印キーで 1 目ずつ動かせる。Delete キー（または「削除」）で消す。「文字を追加」で盤に文字を書ける。文字・着点ボタンの名前は、ダブルクリックで書き換える。
- 「適用」でゲームに保存し、全員の盤に出る（セーブにも残る）。「やめる」で編集を捨てる。「下書きを作り直す」で今の略図からやり直す。
- 運転：カスタム盤の上で、今までの盤と同じように扱える（電子＝信号を押して着点ボタン、継電＝てこ）。在線・進路の色も同じ。
- 「略図」と「カスタム盤」は、ブラウザごとに切り替えられる。
- 編集中は「↶ 戻す」「↷」（Ctrl+Z／Ctrl+Y）で元に戻せる・やり直せる。
- 誰かが編集を始めると、ほかの人の盤に「✎ ○○が盤を編集中」と出る（鍵ではない。同じ会社の人どうしは見分けられない）。
  編集中に編集を始めようとすると確認が出る。編集を始めたあとにほかの人が保存していると、「適用」で置き換える前に確認が出る。
- 編集できるのは、駅の所有会社と操作できる会社。
- 配線を作り直して、部品が結びついたマス・信号がなくなると、その部品は灰色の破線になり、扱えない。
  編集の「合わない部品」で順に選び、「結び直す」を押すと略図に切り替わるので、線路（線・番線は何マスでも、もう一度押すと外す）・信号・ポイント・着点の線路を押して結び直す。
  略図では、どの線にも結びついていない線路（新しく敷いた線路など）が橙色の輪で出る。「＋線路」「＋てこ」「＋ポイント」「＋着点」で部品を足して結べる。
- 「書き出し」でカスタム盤をファイルに保存し、「読み込み」で編集中の盤に読み込める（ほかの駅・ほかのセーブにも写せる。合わない部品は結び直す）。
- マップを回転しても、カスタム盤の絵は変わらない（結びつきだけが回転に合わせて変わる）。

### マグネット・メモ

運転タブの「マグネット・メモ」で道具を選び、地図（略図・カスタム盤のどちらでも）の線路・信号・ポイントを押すと貼れる。全員の盤に出て、セーブにも残る。

- **使用停止**（赤）：貼った線路を通る進路は取れない。信号に貼るとそのてこは扱えず、ポイントに貼るとそのポイントは転換できない。
- **札**：「回送」「臨時」「保守」などの言葉ボタン（または自由な文字）と色を選んで、押すだけで貼れる（表示だけ）。
- **メモ**：付せん。押すと文字を入れる。盤の付せんを押すと開いて、書いた会社と日付が見える（表示だけ）。
- **はがす**：選んでから、はがすものを押す。一覧の ✕ でもはがせる。
- **移す**：貼ってあるものをドラッグして、ほかの線路・信号・ポイントの上で離すと移る（近くに置ける所がなければ元に戻る）。使用停止は移した所で効く。
- 配線を読み直したとき、線路がなくなった所のものは、はがれる。

カスタム盤の編集には飾りの部品もある：文字、矢印（「至 ○○」）、区画の枠（色つき）、時計（OTRP と同じく 1 か月＝1 日として `HH:MM:SS` と「1440 分の何分」）、方位。盤の色（緑盤・灰盤など）も選べる。

### てこの盤を閉じる

継電の盤の右側（運転タブ）のてこの盤は、「▼ てこの盤を閉じる」で閉じられる（地図の上のてこだけで扱うとき）。ブラウザごとに覚える。

### 扱い区分（何人かで扱う大きな駅）

範囲の広い駅を何人かで扱うときは、てこを区分に分ける。

1. 設定タブ「0.」の「扱い区分」で **区分を追加** を押し、名前を付ける（例：東扱い・西扱い。9 区分まで）。
2. その下の一覧で、信号てこ（2 つの信号をまとめたてこは 1 本として）と転てつてこごとに区分を選ぶ。
   選ばなければ「共通」で、誰でも扱える。入換てこは同じ信号の信号てこと同じ区分になる。
3. 運転タブの上の **担当** で、各自が自分の区分を選ぶ（ブラウザごとに覚える）。
   ほかの区分のてこ・ボタンは薄く表示され、押しても扱えない（状態は見える）。「すべて」を選ぶと全部扱える。

継電では、着点待ちのてこは区分ごとに 1 本まで（区分が違えば同時に着点を選べる）。着点ボタンは、その進路の始点のてこに効く。
同じ会社の人どうしはゲームでは見分けられないので、扱えないのは盤の表示の上だけ（取り決めとしての区分）。
進路どうしのぶつかりは、区分・駅をまたいで確かめる。

### 連結（OTRP の連結機能）

時刻表で親編成に「連結相手を待つ」、子編成に「連結する」を設定しておけば、**ピンクのてこ（誘導）** で子編成を親編成のところまで入れられる。
進路は親編成のいる番線・留置線（親編成のマスまで）に引く。子編成は進路の終わりで OTRP の連結処理で親編成に連結する。
親編成のマスまで進路を引けるのはピンクのてこだけ（普通の信号てこ・緑のてこでは在線で取れない）。

- 子編成が通る、てこで扱う信号は **選択信号にして「連結誘導」をオン** にしておく。普通の信号のままだと、
  連結相手がその信号の先の閉塞にいるとき、OTRP は子編成に信号を確かめずに進ませる（連動盤が止められない）。
  これはゲーム側の作りによるもので、盤からは変えられない。ピンクのてこを付けた信号がそうなっていないと、設定タブに注意が出る。
- 番線でも留置線でも連結できる。OTRP は **次の停車駅が同じ** ときだけ連結し、**次の停車駅が分かれる駅を出るとき** に切り離す。
- 連結した列車は 1 本の列車として出発の進路で出る。切り離した後は、それぞれ自分の出発の進路で出る
  （同じ仮想出発信号から、先頭側の列車から順に。後ろに残った列車も、出発点の手前からそのまま出られる）。
- 番線に止まっている子編成を、留置線などで待つ親編成へ連結しに行かせるときは、番線の出発点にピンクのてこを付ける。
  進路がなければ子編成は番線から出ない。
- ピンクの進路は、子編成が来る前に引いておいてもよい（セーブして開き直しても残る）。
- 自動モードの駅では、盤は信号に手を出さないので、OTRP の通常の連結になる。

### セーブデータ

連動盤のデータは、長さ付きのかたまりで保存する。今後の版でデータを足しても、それより前の版の exe で開ける
（知らない部分は読み飛ばす）。これより前の版（データ版数 1〜9）のセーブも開ける。

### 時刻表と番線の関係

時刻表で決まるのは**停車する駅**。盤で同じ駅の別の番線への進路を引くと、列車はその番線に停車して客扱いし、時刻表の次の駅へ進む（時刻表で指定した番線と違っていてよい）。
着点が停車駅以外の場合は、着点から時刻表の行き先へ向かう。行けない場合は信号を停止のままにして「誤進路」と表示する。

ネットワークゲームでも、各自のパソコンでブラウザから自分のゲームに接続して使う。操作はサーバ経由で全員に同期される。

## 手で試す（コンソール）

`python3 interlocking/tools/il_cli.py` で接続し、`PROTOCOL.md` のコマンドを打つ（例: `cmd st_mode,1,1`）。

## 試作版の制約

- 連動区域の入口はすべててこ扱い信号にすること（区域内に自動信号の列車が入り込むのを防ぐ仕組みは入れていない）。
- 進路の途中に、てこ扱いでない信号を置かないこと。
- 車庫・側線などの抜け道の検査は未実装（P1）。
- 盤の設定（表示範囲）はブラウザに保存される。別のブラウザやパソコンでは範囲を指定し直す。
- 接近鎖錠（時素）はない。列車が進入する前なら、いつでも進路を戻せる。

### ネットワークゲームでの表示範囲

盤に描く地図の範囲（設定タブ「2. 表示する範囲」）はゲームに保存され、全員の盤で同じになる。
以前の版で作った駅は、作った人のブラウザにだけ範囲が残っているので、その人が新しい版で一度盤を開くとゲームに送られる。

### 駅の選び方・名前

- 設定タブ「1. 連動駅を作る」の検索欄に駅名の一部を入れると、一覧を絞り込める（ひらがな・カタカナ、全角・半角どちらでもよい）。
- 1 つの駅に作れる連動盤は 1 つ。すでに連動盤のある駅は一覧で「連動盤あり」となり、選べない。
- 番線の両端に仮想出発信号を置いたときは、名前に出ていく向き（東西南北）を付ける（例：2番線出発（東））。
